      Arti animasi

      • Mengetik di meja. Agent sedang plan atau implement. Layar menampilkan teks atau kode yang bergulir.
      • Tiga bar di layar. Verify: lint, typecheck, test. Kuning sedang jalan, hijau lolos, merah gagal.

      • Dokumen terbang. Handoff artifact antar agent: requirements.md, verify-report.md, qa-report.md.
      • Tangan terangkat, layar merah. NEEDS_HUMAN. Pipeline berhenti dan lampu di meja Ganjar menyala merah.

      • Lampu hijau di meja Ganjar. PR sudah dibuka dan menunggu review manusia. Tidak ada auto-merge.
