    Status agent

      Arti animasi

      • Mengetik di meja. Agent sedang plan atau implement. Layar menampilkan teks atau kode yang bergulir.
      • Minum kopi di meja. Agent sedang idle. Setiap agent selalu duduk di mejanya sendiri; hanya pose dan layarnya yang berubah.
      • Tiga bar di layar. Verify: lint, typecheck, test. Kuning sedang jalan, hijau lolos, merah gagal.
      • Garuk kepala. Verify gagal, agent mengulang. Batasnya tiga percobaan untuk agent implementasi.
      • Dokumen terbang. Handoff artifact antar agent: requirements.md, verify-report.md, qa-report.md.
      • Tangan terangkat, layar merah. NEEDS_HUMAN. Pipeline berhenti dan lampu di meja Ganjar menyala merah.
      • Api kecil di kepala. ERROR. Exception yang akan dicoba ulang oleh BullMQ.
      • Lampu hijau di meja Ganjar. PR sudah dibuka dan menunggu review manusia. Tidak ada auto-merge.
      • Tertidur di sofa pantry. caf-documentation sengaja belum di-instrument, jadi ia tampil off duty.

      Halaman ini hanya membaca: kejadian, waktu, dan biaya berasal dari pipeline_runs dan agent_events. Bar lint, typecheck, dan test hanya dianimasikan di mode demo; pada run nyata hasil verify dibaca dari verify-report.md setelah agent selesai.
