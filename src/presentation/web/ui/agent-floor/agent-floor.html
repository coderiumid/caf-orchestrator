    Agent status

      Animation guide

      • Typing at the desk. The agent is planning or implementing. The screen shows scrolling text or code.
      • Sipping coffee at the desk. The agent is idle. Every agent always sits at its own desk; only its pose and screen change.
      • Three bars on the screen. Verify: lint, typecheck, test. Yellow is running, green passed, red failed.
      • Scratching head. A check or gate failed and the agent is retrying. Implementation agents get three verify attempts.
      • Flying document. An artifact handed from one agent to the next: requirements.md, verify-report.md, qa-report.md.
      • Raised hand, red screen. NEEDS_HUMAN. The pipeline stopped and the lamp on the Manager's desk turns red.
      • Small flame overhead. ERROR. An exception that BullMQ will retry.
      • Green lamp on the Manager's desk. A PR is open and waiting for human review. There is no auto-merge.
      • Asleep at the desk, head down. caf-documentation is deliberately not instrumented, so it is shown off duty.

      This page is read-only: events, times, and costs come from pipeline_runs and agent_events. The lint, typecheck, and test bars only animate in demo mode; for a real run the verify result is read from verify-report.md after the agent finishes.
